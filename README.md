# Scrape

This repository contains a Python script and some agent skills for web scraping. 

## Files

* `scrape.py`: A Python script used to extract emails and other data from company websites.
* `.agents/skills/web-scraping/`: A directory that stores Markdown documentation and code examples for different scraping strategies. It has information about bypassing anti-bot measures, using Apify, and discovering APIs.
* `.agents/skills/multi-tiered-scraping/`: Documentation for a multi-tiered approach to data extraction.
* `.agents/skills/responsible-engineer/`: Guidelines for engineering and code reviews.

## Usage

To use the Python script, install the required dependencies and run `scrape.py`. The output data is saved as CSV and JSON files (e.g., `companies.csv`, `company_emails_100.json`).

For the agent skills, read the `SKILL.md` files located in each subdirectory under `.agents/skills/` to understand how to apply them.
